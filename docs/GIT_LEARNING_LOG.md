# Git Learning Log

A log for recording Git commands, workflow operations, and terminal insights during development sessions.

---

## Template

### Session
- Date: YYYY-MM-DD

### Objective
- Goal of the session.

### Commands Executed
```bash
git <command>
```

### Why Each Command Was Used
- **`git <command>`**: Explanation of why this command was invoked.

### Errors Encountered
- Description of any errors or unexpected outputs.

### Resolution
- Steps taken to resolve the encountered errors.

### Concepts Learned
- Key takeaways and concepts understood.

### Notes
- Additional observations or references.
